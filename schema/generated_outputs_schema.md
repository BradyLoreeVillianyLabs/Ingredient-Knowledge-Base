# Generated Outputs Schema

These files are produced by scripts and should not be manually edited unless debugging.

## `data/generated/ingredient_alias_index.csv`

Generated by `scripts/build_alias_index.py`.

| Column | Description |
|---|---|
| `ingredient_id` | Stable ingredient identifier from source CSV rows. |
| `canonical_name` | Preferred ingredient display name. |
| `alias` | Original alias or canonical name. |
| `normalized_alias` | Search/OCR normalized alias. |
| `source_file` | CSV file where the alias came from. |
| `review_status` | Usually `generated`. |

## `data/generated/ingredient_frequency.csv`

Generated by `scripts/mine_openfoodfacts.py`.

| Column | Description |
|---|---|
| `ingredient_name` | Normalized ingredient term mined from labels. |
| `product_count` | Number of product rows containing the term. |
| `top_category` | Most common category field among products containing the term. |
| `top_country` | Most common country field among products containing the term. |
| `raw_example` | Example ingredient label snippet. |
| `review_status` | Usually `mined`. |

## `data/generated/ingredient_combinations.csv`

Generated by `scripts/mine_openfoodfacts.py`.

| Column | Description |
|---|---|
| `ingredient_a` | First normalized ingredient term. |
| `ingredient_b` | Second normalized ingredient term. |
| `cooccurrence_count` | Number of products where both appeared together. |
| `review_status` | Usually `mined`. |

## `data/generated/unknown_ingredient_candidates.csv`

Generated by `scripts/mine_openfoodfacts.py`.

| Column | Description |
|---|---|
| `candidate_name` | Rare normalized ingredient term. |
| `product_count` | Number of products containing the term. |
| `raw_example` | Example label snippet. |
| `review_status` | Usually `needs_review`. |
